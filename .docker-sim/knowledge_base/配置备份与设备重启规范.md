# 配置备份与设备重启规范

## 问题现象
设备配置丢失/回滚、重启后业务异常、版本升级失败；需要建立配置备份与变更的规范化操作流程。

## 排查步骤
1. 配置备份方法：
   ```
   display current-configuration
   save
   ```
   - 华为设备 save 后配置保存到 flash 的配置文件；
   - 定期用 FTP/SFTP/网管把配置文件拉取归档，或配置定时备份。

2. 核对配置与运行状态：
   ```
   display startup
   display saved-configuration file
   ```
   - 确认当前运行配置与下次启动加载的配置一致；
   - 版本升级/重启前核对 startup saved-configuration 指向正确文件。

3. 重启前检查清单：
   - 保存配置（save）确认无未保存修改；
   - 检查电源冗余（双电源）、关键链路冗余；
   - 通知业务窗口，确认重启影响范围。

4. 升级规范：
   - 下载官方版本包，核对 MD5 校验值；
   - 上传后 `display patch-information`/检查版本兼容性；
   - 先单台验证（测试环境），再批量灰度。

5. 回退预案：
   - 保留旧版本/旧配置文件的备份；
   - 明确回退步骤与回退判定条件（如 10 分钟未恢复即回退）。

## 常见风险与处置
| 风险 | 处置 |
|---|---|
| 未 save 配置丢失 | 变更前 save，变更后复查 |
| 启动文件指向错误 | display startup 核对并修正 |
| 升级失败 | 保留旧版本文件，走回退流程 |
| 配置被覆盖 | 变更前备份当前配置 |
| 重启影响业务 | 窗口期操作，确认冗余 |

## 注意事项
"配置备份—变更—验证—回退"四步是网络变更的铁律；任何生产设备变更前必须能回答三个问题：改了什么、怎么回退、失败了怎么办。
