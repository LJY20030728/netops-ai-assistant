# 光模块收发光功率与误码专项排查

## 问题现象
长距离/高速链路出现间歇性丢包、CRC 错误增长、端口 up/down 抖动；光模块收发光功率异常（光衰大、发光弱、接收无光）。

## 排查步骤
1. 查看光模块信息与收发光功率：
   ```
   display transceiver interface <端口>
   display transceiver diagnostic-information
   ```
   - 关注 TX Power（发送功率）、RX Power（接收功率）、温度、电压；
   - 对比阈值（低阈值/高阈值）：RX Power 接近低阈值 = 光衰严重。

2. 判断功率是否正常：
   - 接收功率低于接收灵敏度（如 -23dBm 以下）会大量误码；
   - 发送功率异常（过高或过低）检查光模块本身；
   - 长期运行的光模块功率会逐渐劣化。

3. 检查误码与错误计数：
   ```
   display interface <端口>
   ```
   - CRC/FCS 错误增长 = 物理层误码，通常光信号质量差导致；
   - 错误在接收侧（RX）增长说明本端收到的光信号差。

4. 检查光纤与连接：
   - 检查光纤端面是否脏污（用光纤显微镜/清洁笔）；
   - 检查收发是否接反（TX-RX 交叉）、弯曲半径是否过小；
   - 用光功率计实测链路损耗，对比理论值。

5. 交叉验证：
   - 更换跳线、更换光模块、更换端口做 A/B 对比，定位故障段。

## 常见根因与处置
| 根因 | 处置 |
|---|---|
| 光衰过大 | 清洁端面、更换跳线、检查熔接点 |
| 光模块老化 | 更换光模块 |
| 收发接反 | 检查并纠正收发交叉 |
| 光口脏污 | 用清洁笔/棉签清洁 |
| 链路损耗超标 | 核算链路预算，增加中继/改用高功率模块 |

## 注意事项
光模块排障先看功率数值（TX/RX 是否在阈值内），再看错误计数（CRC 增长方向），最后做交叉替换验证；功率是"因"，误码是"果"。
