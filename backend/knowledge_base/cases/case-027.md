# 案例027：某楼层 WiFi 信号全无（AP 离线）

【告警类型】WIFI_AP_OFFLINE
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"三楼 wifi 突然全没信号了，手机都连不上，ap 是不是离线了"。三楼所有无线终端无法连接 WiFi，办公受影响。

## 排查过程
1. 无线控制器查看 AP 状态：该楼层多个 AP 显示离线；
2. `display ap uptime`：AP 掉线时间一致，怀疑 PoE 交换机故障；
3. 检查 PoE 交换机：该楼层接入交换机供电模块异常，多个端口无 PoE 输出；
4. 更换供电模块后 AP 逐个上线，无线恢复。

## 根因
楼层 PoE 接入交换机供电模块故障，多个 AP 同时断电离线，无线覆盖整体丢失。

## 处置
更换 PoE 供电模块；AP 在线率纳入监控；PoE 交换机做冗余供电规划。
