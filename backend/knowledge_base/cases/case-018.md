# 案例018：设备重启后配置全部丢失

【告警类型】CONFIG_LOST
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"重启了一下设备，配置全没了，回到出厂状态"。机架交换机断电重启后，全部配置丢失，业务中断。

## 排查过程
1. `display startup`：启动配置文件为空（无 saved-configuration）；
2. `display saved-configuration`：Flash 中无备份配置；
3. 核查变更记录：该设备配置后未执行 `save`，配置只存在于运行态；
4. 从配置备份服务器恢复配置并执行 `save`。

## 根因
配置变更后未执行 save 持久化，断电/重启后运行配置全部丢失。

## 处置
变更后强制 save + 配置备份服务器每日自动备份；建立"变更必须 save"的流程检查项。
