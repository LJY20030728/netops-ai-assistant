# 案例002：接入交换机下设备频繁掉线重连（协商不匹配）

【告警类型】LINK_FLAPPING
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
用户反馈"交换机接口上的设备老是掉线重连，一天好几次"，设备为老款打印机和 IP 电话，掉线后重启设备能恢复一段时间。

## 排查过程
1. `display interface brief`：该端口存在大量 CRC 错误计数；
2. `display interface`：本端为自协商 1000M 全双工，但对端设备仅支持 100M；
3. 强制端口协商模式：`speed 100` + `duplex full` 后 CRC 停止增长，掉线消失。

## 根因
对端老旧设备与交换机自协商结果不稳定（速率/双工不匹配），产生 CRC 错误触发链路抖动。

## 处置
端口强制 100M 全双工；记录兼容性清单，避免同款老旧设备再次接入引发 flapping。
