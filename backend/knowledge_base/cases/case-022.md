# 案例022：光模块误码剧增（收光功率 -30dBm）

【告警类型】OPTICAL_POWER_LOW
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"机房温度有点高，顺便看了下光模块，误码很多，收光功率-30dbm 是不是不正常"。巡检发现某核心链路光模块误码暴增，收光功率异常低。

## 排查过程
1. `display transceiver interface`：RX 功率 -30dBm（远低于 -28dBm 阈值），误码计数持续增长；
2. `display interface`：CRC 错误与 FCS 错误同步上升；
3. 检查光纤：该段光纤存在 90° 直角弯折（机柜走线挤压），更换布线路由后功率恢复；
4. 功率恢复正常后误码停止增长，业务时延回落。

## 根因
光纤过度弯折导致光损耗剧增（收光功率 -30dBm），链路误码率上升，业务质量劣化。

## 处置
整改机柜布线（控制弯曲半径）；光功率与误码纳入自动巡检指标，低于阈值自动告警。
