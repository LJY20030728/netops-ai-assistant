# 案例004：光模块接收功率过低（光模块故障）

【告警类型】OPTICAL_POWER_LOW
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
用户反馈"光模块是不是有问题，接收功率太低，网时好时坏"。某业务链路丢包率升高，业务时断时续。

## 排查过程
1. `display transceiver interface`：RX 光功率 -29dBm（低于告警阈值），TX 正常；
2. `display interface`：该端口 CRC 误码持续增长；
3. 交叉测试：将光模块换到另一台设备仍为低功率，确认模块自身劣化（非光纤/对端问题）；
4. 更换光模块后功率恢复 -13dBm，误码清零。

## 根因
光模块老化劣化导致接收灵敏度下降，接收功率过低触发链路误码与不稳定。

## 处置
更换光模块；建立备件库并记录模块使用年限，超期模块纳入主动更换计划。
