# 案例024：内网无法访问外网（NAT 转换失败）

【告警类型】NAT_FAILURE
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"内网电脑上不了外网，nat 是不是挂了"。所有内网终端无法访问互联网，但内网互访正常，防火墙 NAT 会话表异常。

## 排查过程
1. `display nat session-table`：无新建会话，NAT 地址池耗尽；
2. `display nat address-group`：公网地址池 32 个地址全部被占用（长连接未释放，会话老化时间被调为超长）；
3. 核查：某业务大量建立不释放的长连接，占满 NAT 地址池；
4. 临时扩容地址池 + 恢复会话老化时间后，外网访问恢复。

## 根因
NAT 地址池被异常长连接占满，无法为新建会话分配公网地址，内网无法访问外网。

## 处置
扩容 NAT 地址池并恢复正常会话老化；对异常长连接应用限流；NAT 地址池利用率纳入监控告警。
