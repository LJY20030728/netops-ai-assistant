# 案例025：业务突然不通（ACL 误拦正常流量）

【告警类型】ACL_DENY
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"今天做了一次安全策略调整，之后财务系统突然全都不通了，是不是 acl 拦了"。安全策略变更后，某网段访问财务系统全部失败。

## 排查过程
1. `display acl all`：核对新下发 ACL 规则顺序——新增的 deny 规则匹配范围过宽（/16 误写成 /8）；
2. `display packet-filter interface`：确认接口应用了该 ACL；
3. 命中计数验证：`display acl counter` 显示 deny 规则计数快速增长，正是财务网段流量；
4. 修正 ACL 掩码范围并重新下发后，业务恢复。

## 根因
ACL 变更时掩码写错导致 deny 规则覆盖范围过宽，误拦正常业务流量。

## 处置
修正 ACL 并走变更审批；策略变更后抽样验证关键业务连通性；ACL 规则使用前先做匹配范围测试。
