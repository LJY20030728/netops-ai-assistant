# 案例020：跨网段访问时通时断（静态路由下一跳不可达）

【告警类型】ROUTE_FLAKY
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
跨网段访问时通时断，路由表看着没问题。A 网段访问 B 网段业务间歇性失败，本机路由表显示有到对端网段的静态路由。

## 排查过程
1. `display ip routing-table`：静态路由条目存在；
2. 逐跳 `tracert`：报文在下一跳设备处丢失；
3. 检查下一跳设备：其对端接口 down（链路物理故障），但静态路由无失效检测（未配置 BFD/联动）；
4. 修复链路 + 静态路由联动 BFD 后，路由快速收敛，时通时断消失。

## 根因
静态路由下一跳物理链路故障，路由条目静态存在但实际不可达，报文在黑洞处被丢弃。

## 处置
修复物理链路；静态路由配置 BFD 联动实现快速失效切换；核心链路做冗余备份。
