# 案例013：全楼电脑拿不到地址（DHCP 地址池耗尽）

【告警类型】DHCP_POOL_EXHAUSTED
【来源】reference（参考华为企业技术支持社区 DHCP 排障案例改编）

## 工单现象
"公司电脑突然全部拿不到地址了，显示未识别网络"。某楼层新到岗 20 台终端，全部无法获取 IP，老终端也不断掉线重连。

## 排查过程
1. `display ip pool`：地址池已分配 254/254，dhcp pool 满了，无可用地址；
2. `display dhcp server statistics`：NAK 报文计数暴涨；
3. 核查租约：租期 7 天过长 + 存在大量僵尸租约（离职终端未释放）；
4. 临时扩容地址池 + 缩短租期后终端恢复获取地址。

## 根因
DHCP 地址池耗尽（254/254），租期过长且僵尸租约未释放，新终端拿不到地址，老终端续租失败被 NAK。

## 处置
扩容地址池、缩短租期、清理僵尸租约；接入层启用 DHCP snooping 防私建 DHCP 服务器。
