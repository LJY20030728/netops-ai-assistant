# 案例029：夜间业务卡顿（备份任务占满带宽）

【告警类型】LINK_CONGESTION
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"最近晚上业务就卡，白天没事，看了下是备份任务把带宽吃满了，想限速"。夜间备份窗口期间业务系统访问缓慢。

## 排查过程
1. 时间关联：卡顿集中在每日 22:00-02:00 备份窗口；
2. `display interface`：备份时段上联带宽利用率 95%+；
3. 抓包确认：备份服务器全速推送增量数据，无 QoS 限速；
4. 对备份流量配置带宽限速（CIR/PIR）并保障关键业务队列后，夜间业务恢复流畅。

## 根因
夜间备份任务未做限速，占满出口带宽，与正常业务争抢队列导致业务卡顿。

## 处置
备份流量 QoS 限速 + 业务高优先级队列；备份窗口与业务高峰错峰；建立带宽利用率基线告警。
