# 案例003：机房交换端口闪断导致全网卡顿（光衰临界）

【告警类型】LINK_FLAPPING
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"早上开会说网络卡，后来发现是机房那边交换机端口一直闪，一会儿通一会儿断"。核心链路忽快忽慢，会议系统频繁掉线。

## 排查过程
1. `display interface brief`：核心互联端口状态频繁 up/down；
2. `display transceiver interface`：接收光功率 -26dBm（接近 -28dBm 告警阈值），发送正常；
3. `display logbuffer`：端口反复上报 Link down/up 事件；
4. 清洁光纤端面后功率回升至 -14dBm，链路恢复稳定。

## 根因
光纤端面脏污导致收光功率临界，链路在功率阈值边缘反复闪断（flapping），造成全网体验卡顿。

## 处置
清洁光纤端面；建立光功率月度巡检基线，低于 -22dBm 提前预警更换。
