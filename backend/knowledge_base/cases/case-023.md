# 案例023：内网域名解析失败（DNS 服务器故障）

【告警类型】DNS_FAILURE
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"公司内网突然访问不了内部系统，域名解析不了，ip 直连能通"。用户访问内网系统报"找不到服务器"，但用 IP 直连正常。

## 排查过程
1. `nslookup` 内网域名：返回超时/ServFail；
2. 检查 DNS 服务器：`display tcp status` 确认 UDP 53 端口服务异常，DNS 进程崩溃未自动拉起；
3. 检查 DNS 服务器与客户端的连通性：防火墙规则误删了 DNS 查询放行条目；
4. 恢复防火墙放行规则并重启 DNS 服务后，域名解析恢复正常。

## 根因
防火墙误删 DNS 放行规则，客户端查询报文被丢弃，内网域名解析全部失败（IP 直连不受影响）。

## 处置
恢复防火墙放行规则；DNS 服务状态纳入监控；防火墙变更走双人复核流程。
