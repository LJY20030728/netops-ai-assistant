# 案例016：内网拥塞（广播泛洪引发）

【告警类型】LINK_CONGESTION
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
内网某区域整体变慢，核心链路时延上升。排查发现存在异常广播流量泛洪叠加正常业务流量，导致链路拥塞。

## 排查过程
1. `display interface counters`：核心互联端口广播计数异常增长；
2. `display cpu-usage`：相关交换机 CPU 升高；
3. 抓包确认广播源为某接入端口（环路产生 BPDU 丢失），结合 STP 状态判断存在二层环路；
4. 阻断环路端口后广播消失，链路拥塞解除。

## 根因
二层环路导致广播泛洪，与正常业务流量叠加造成核心链路拥塞。

## 处置
阻断环路端口；全面核查 STP 配置；启用环路检测（loop-detect）自动阻断。
