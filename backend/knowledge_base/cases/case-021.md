# 案例021：VRRP 主备切换后业务全断（心跳链路故障双主）

【告警类型】VRRP_FAILOVER
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
VRRP 网关冗余主备切换后业务全断。两台核心交换机做 VRRP 双机，某次切换后出现两个 Master，终端网关地址冲突。

## 排查过程
1. `display vrrp`：两台设备同时显示 Master 状态（双主）；
2. 检查心跳/互联链路：主备间互联口 down（物理链路故障），VRRP 通告报文无法互达；
3. 两端优先级相同 + 无抢占延迟配置，链路恢复后状态未收敛；
4. 修复互联链路并配置抢占延迟 + 上联跟踪后，VRRP 恢复单 Master。

## 根因
VRRP 心跳链路中断导致主备互不可见，形成双 Master；优先级/抢占配置不完善使恢复后无法收敛。

## 处置
修复心跳链路；配置抢占延迟与上联链路跟踪；VRRP 状态纳入监控告警。
