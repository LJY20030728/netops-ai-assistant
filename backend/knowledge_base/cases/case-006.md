# 案例006：新增连线后全网瘫痪（二层环路）

【告警类型】STP_TOPOLOGY_CHANGE
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"两台交换机连了根线，全网就卡死了，是不是环了"。新增一根交换机间连线后，全网广播流量飙升、设备 CPU 打满、业务全部中断。

## 排查过程
1. `display cpu-usage`：多台交换机 CPU 接近 100%；
2. `display interface counters`：部分端口广播/组播计数暴涨；
3. `display stp brief`：新连线所在端口 STP 未收敛（处于 Listening/Learning），说明新增链路形成环路且 STP 未及时阻断；
4. 拔除新增连线后网络立即恢复。

## 根因
新增连线构成二层物理环路，STP 收敛异常（端口角色计算错误）导致广播风暴。

## 处置
拔线恢复业务；复核 STP 根桥/端口优先级配置；变更流程中新增"环路风险评估"检查项。
