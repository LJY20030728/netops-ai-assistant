# 案例028：多告警叠加的综合故障（核心链路割接后异常）

【告警类型】LINK_FLAPPING
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
"周末做了一次核心链路割接，周一上班发现网络慢、还间歇性断，监控同时报了光功率低和端口抖动"。割接后多个告警叠加：链路时通时断、光功率异常、部分业务超时。

## 排查过程
1. 告警关联：LINK_FLAPPING + OPTICAL_POWER_LOW 同时上报，指向同一条核心互联链路；
2. `display transceiver interface`：收光功率 -27dBm（临界），且为割接后新熔接的光纤段；
3. `display interface`：端口 flapping 计数持续增长；
4. 检查新熔接点：熔接质量差导致损耗过大，重新熔接后功率恢复 -15dBm，flapping 停止。

## 根因
割接时新熔接的光纤段熔接质量差，损耗过大导致收光功率临界，链路在阈值边缘反复抖动——多告警实为同一根因。

## 处置
重新熔接并测试损耗；割接验收增加光功率与误码专项检查；告警关联分析（同一时间窗/同一链路）纳入 AI 助手分析流程。
