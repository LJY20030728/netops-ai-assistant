# 案例019：全网周期性掉线（ARP 欺骗仿冒网关）

【告警类型】ARP_CONFLICT
【来源】simulated（模拟工单，按常见故障模式编写）

## 工单现象
全网终端周期性掉线，网关 MAC 异常。用户反映"网络每隔一段时间全部断一下"，断网期间 ping 网关不通。

## 排查过程
1. `display arp`：网关 IP 对应多个不同 MAC，存在 ARP 冲突；
2. `display mac-address`：仿冒网关 MAC 出现在某接入端口；
3. 断开该端口后 ARP 表恢复正常，全网不再掉线；
4. 确认该终端中毒持续发送伪造网关 ARP 报文。

## 根因
终端中毒仿冒网关 IP/MAC 发送伪造 ARP，全网 ARP 表被污染，流量被劫持/丢弃导致周期性断网。

## 处置
隔离中毒终端并查杀；网关启用 ARP 防攻击（DAI）；接入端口做 MAC+IP 绑定。
