# 网络设备日常巡检与基线

## 巡检目标
在故障发生前发现隐患：光衰劣化、资源使用率、配置漂移、异常日志。

## 巡检命令清单

```
show version                          # 版本与运行时长
show cpu usage / show process cpu     # CPU 利用率
show memory                           # 内存
show interfaces status                # 端口状态总览
show interfaces counters errors       # 错误计数
show interface <端口> transceiver     # 光模块功率
show logging                          # 系统日志
show clock                            # 时间（检查 NTP 同步）
show vlan brief                       # VLAN 与端口成员
show spanning-tree summary            # STP 状态
show bgp summary / show ip ospf neighbor   # 路由协议状态
show running-config | compare ...     # 配置漂移检测
```

## 基线化方法
- 首次建立各设备正常基线（光功率、CPU、内存、端口错误率）。
- 设置阈值：CPU 持续 >70%、内存 >80%、Rx 功率接近下限、错误计数持续增长 → 告警。
- 定期比对当前值与基线，差值超阈值即触发人工复核。

## 巡检频率建议
- 核心设备：每日自动采集 + 每周人工抽查。
- 接入设备：每周自动采集。
- 重大变更后：立即采集一次基线。

## 变更管理要点
- 变更前：备份配置、记录基线。
- 变更中：逐条执行、观察状态。
- 变更后：对比基线、回滚预案、更新文档。
