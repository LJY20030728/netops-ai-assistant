# 光模块与光纤链路排查

## 常用命令

```
show interface transceiver <端口号>          # 查看光模块诊断信息
show interface <端口号> transceiver detail    # 详细光功率
show interface <端口号> status
show environment                          # 温度、电压等环境信息
```

## 关键指标解读

- **Tx Power（发送光功率）**：过高或过低都异常。过高说明可能损坏或对接错误。
- **Rx Power（接收光功率）**：低于接收灵敏度（RX threshold）会导致误码、丢包乃至 down。
- **光衰预算**：链路总损耗 = 发送功率 - 接收功率，需小于模块预算（如 10km 单模约 8dB 预算）。
- **温度**：光模块工作温度超标会导致功率漂移、链路抖动。

## 排查流程

1. 检查 Rx Power 是否处于正常范围（对比模块规格书阈值）。
2. 光衰过大时：
   - 清洁光纤端面（用专用清洁笔/无尘纸）；
   - 检查光纤是否有过度弯曲、挤压、熔接损耗；
   - 检查是否错用多模/单模光纤；
   - 检查法兰盘/尾纤接头是否松动。
3. 交换验证法：用已知正常的跳线和模块替换，逐段排除（设备端口 → 跳线 → 配线架 → 对端）。
4. 记录光功率基线：正常时记录基线，异常时对比，便于快速定位衰减点。

## 常见原因
- 光纤端面污染（最常见）；
- 光纤弯曲半径过小；
- 模块与光纤模式不匹配（MM/SM）；
- 模块老化或损坏；
- 对端未上电/端口 shutdown。
