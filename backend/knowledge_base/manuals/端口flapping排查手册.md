# 端口 flapping 排查手册

【故障关键词】flapping、端口抖动、接口反复 up/down、时通时断、CRC 错误增长、协商异常、断网重连、掉线重连、设备掉线


## 问题现象
端口状态在 up 与 down 之间频繁切换，伴随接口计数器的 up/down 次数持续增长，业务出现间歇性中断。

## 排查步骤

1. 查看端口当前状态与错误计数：
   ```
   show interface <端口号>
   show interface <端口号> counters
   show interface <端口号> status
   ```
   重点关注：input errors、output errors、CRC、FCS、runts、giants、up/down 次数。

2. 检查物理层：
   - 检查光模块收发光功率是否在阈值内（光衰过大会导致信号不稳定）；
   - 更换跳线或光模块做交叉验证；
   - 检查接口是否松动、水晶头/光纤端面是否脏污。

3. 检查链路层协商：
   - 双工模式不匹配（一方 auto，一方强制）是 flapping 的常见原因；
   - 速率协商失败（两端速率不一致）；
   - 检查两端是否都开启或都关闭自协商。

4. 检查生成树（STP）与环路：
   - 端口在 STP 状态（blocking/forwarding）间震荡时，检查是否存在环路；
   - 查看 STP 拓扑变化计数：`show spanning-tree summary`。

5. 检查对端与日志：
   - `show logging | include <端口号>` 查看端口相关日志；
   - 联系对端管理员确认对端设备同样现象。

## 常见根因与处置
| 根因 | 处置 |
|---|---|
| 光衰过大 | 清洁/更换光纤、检查光模块 |
| 双工/速率不匹配 | 两端统一为 auto 或一致的双工速率 |
| 物理接触不良 | 重新插拔、更换端口 |
| 环路导致 STP 震荡 | 排查并剪断环路，检查 STP 配置 |
| 硬件故障 | 更换板卡/端口，申请备件 |
