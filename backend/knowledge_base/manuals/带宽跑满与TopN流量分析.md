# 带宽跑满与TopN流量分析

## 典型症状
骨干接口带宽告警但不知谁在跑；SNMP 只给总量无法下钻。

## 原理速记
接口总量是聚合，需流分析（NetFlow/sFlow）按五元组下钻；结合应用识别定位是业务还是异常。

## 排查步骤
- `display interface rate` —— 确认哪接口、方向
- `display ip netflow cache top talkers` —— 按源目排序
- `抓包结合 ACL` —— 确认具体应用

## 常见根因
某主机病毒/挖矿外联；备份流量走错出口；视频业务未限流。

## 处置与验证
TopN 源 IP 明确；针对性阻断/限速；带宽回落告警解除。
