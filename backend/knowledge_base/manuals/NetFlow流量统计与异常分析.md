# NetFlow流量统计与异常分析

## 典型症状
需要定位谁在跑满带宽，但 SNMP 只给接口总数；NetFlow 未导出或抓不全。

## 原理速记
NetFlow 按流（源目 IP/端口/协议五元组）聚合；设备将流导出到采集器，需配置模板与采样率。

## 排查步骤
- `display ip netflow cache` —— 看本地流表是否有流生成
- `display ip netflow export` —— 看导出目的地址、UDP 9995/2055 连通
- `采集器侧确认收到 flow` —— 模板是否版本 v9

## 常见根因
导出服务器不可达；采样率过高导致大流被忽略；接口未应用 netflow 配置。

## 处置与验证
采集器收到流；按源 IP 排序能看到 TopN 流量；可定位异常主机。
